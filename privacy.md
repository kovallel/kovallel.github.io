# Privacy policy — Valheim Backup

Valheim Backup is a personal backup setup operated by the owner of this site.

It uses the Google Drive API with the `drive.file` permission to upload Valheim world backup files and access files it has created in Google Drive. The files may contain game world and player data.

Backups are stored in the owner's Google Drive. OAuth credentials are stored on the owner's home server. This setup has no analytics and does not sell or share backup data with other parties.

The owner can delete the backups from Google Drive and revoke the app's access in Google Account settings.
